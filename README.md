# Social Marketplace

A modern social marketplace that combines social networking with online commerce.

## Features

- User authentication
- User profiles
- Social feed
- Marketplace listings
- Real-time messaging
- Search and discovery
- Notifications
- Responsive web application

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python
- SQLite (development)
- PostgreSQL (production)

## Project Structure

```
social-marketplace/
├── frontend/
├── backend/
├── shared/
├── docs/
└── docker/
```

## Getting Started

### Prerequisites

- Node.js 20+
- Python 3.12+
- Docker (optional)

### Installation

```bash
git clone https://github.com/csurrin-alt/social-marketplace.git
cd social-marketplace
```
